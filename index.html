Как изменить игры

Все категории и игры лежат прямо в файле data.js. Для GitHub Pages достаточно заменить массивы внутри объекта GAME_DATA.

const GAME_DATA = {
  "Моя категория": ["Игра 1", "Игра 2", "Игра 3"]
};

После изменения загрузите обновлённые файлы в репозиторий GitHub. Сервер не нужен: сайт полностью статический.
